# Limitations

- NASA POWER is a gridded source; a returned coordinate is not an exact satellite-pixel observation.
- Nearby spatial requests may snap to the same effective source cell.
- The spatial grid is exploratory context, not independent regional proof.
- The application investigates selected variables and does not represent every Earth-system process.
- Monotonic trend summaries do not describe every nonlinear change or regime shift.
- Short or incomplete records may support descriptive output only.
- Missing data is not treated as zero, and missing months are not silently interpolated.
- Monthly data cannot establish daily event impact.
- EONET and FIRMS have source-specific coverage and availability limits.
- FIRMS context depends on server-side credentials and may be reported as not configured.
- An event record does not establish that climate change caused the event.
- Association does not establish causation.
- A non-significant result does not prove that no trend exists.
- The application is a challenge prototype and should not be used as an operational warning, public-safety system, or attribution authority.
- The repository currently contains documentation and presentation materials; the complete Builder project source was not exported into this repository at the time of this update.
- The public demo URL listed in the README should be checked before submission because the app's publication status can change independently of this repository.
