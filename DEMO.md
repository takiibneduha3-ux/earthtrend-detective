# Demo Guide

## Public demo

Current demo URL listed by the project report:

<https://earth-trend-detective.base44.app/>

Verify that the URL is publicly reachable before submitting it.

## Suggested walkthrough

1. Open Investigate.
2. Use a named location and selected NASA POWER variable.
3. Run the investigation with a documented time range.
4. Show the quality gate and complete-year coverage.
5. Explain the Theil–Sen slope and the selected significance method.
6. Open Spatial Evidence and explain that the grid is exploratory context.
7. Open Event Context and explain that event context is separate from trend evidence.
8. Open Evidence Replay.
9. Show the source, method, timestamp, limitations, and export hash.

## Safe explanation

The application reports statistical evidence in a selected NASA data series. It does not establish climate causation, event attribution, or independent regional proof from a gridded spatial sweep.
